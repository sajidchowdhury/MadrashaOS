     1→// ============================================================
     2→// MadrashaOS — Prisma Schema (Phase B0.3)
     3→// ============================================================
     4→// Implements the 52-table PostgreSQL schema defined in:
     5→//   - docs/ERD.md             (52 tables, 98 relations, 14 enums)
     6→//   - docs/DATA_DICTIONARY.md  (per-table field definitions)
     7→//   - src/lib/mock/types.ts    (data contract from the mock layer)
     8→//
     9→// Layer breakdown:
    10→//   Foundation    (10) — organizations, branches, users, roles, permissions,
    11→//                          role_permissions, audit_logs, module_configs,
    12→//                          security_policies, backup_records
    13→//   People         (9) — classes, sections, students, guardians,
    14→//                          student_guardians, teachers, employees,
    15→//                          admissions, teacher_assignments
    16→//   Academic       (8) — subjects, routines, attendance_sessions,
    17→//                          attendance_records, exams, marks, results,
    18→//                          student_history
    19→//   Finance        (9) — accounts, fee_plans, fee_installments,
    20→//                          fee_payments, scholarships, ledger_entries,
    21→//                          cash_bank_transfers, zakat_transactions, donations
    22→//   Operations    (12) — inventory_items, purchases, purchase_items,
    23→//                          suppliers, assets, hostel_rooms, hostel_beds,
    24→//                          meal_plans, library_books, library_issues,
    25→//                          vehicles, fuel_logs
    26→//   Communication  (4) — notices, documents, reports, approvals
    27→//                       ──────────────────────
    28→//                       Total: 52 tables
    29→//
    30→// Conventions:
    31→//   • snake_case field names (mirror DB columns; no @map needed)
    32→//   • PascalCase model names mapped via @@map to snake_case plural tables
    33→//   • UUID PKs (uuid_generate_v4 via Prisma default)
    34→//   • Money = Decimal(14, 2); JSONB = Json
    35→//   • Soft-delete (deleted_at) on every table
    36→//   • Multi-tenant scoping (organization_id, branch_id) on every table
    37→//     except organizations (root) and permissions (global catalog)
    38→//   • created_by / updated_by kept as plain UUID scalars (audit fields)
    39→//     to avoid bloating User with 100+ back-relations
    40→// ============================================================
